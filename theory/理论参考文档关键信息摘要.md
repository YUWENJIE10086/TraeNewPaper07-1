## 一、0728.docx —— 烟草行业数字化转型全景与营销异动智能闭环

### 1.1 文档主题和核心理论框架

**文档主题：** 烟草行业一体化平台综合应用 —— 数字技术与烟草产业深度融合的全景规划与实施路径。

**核心理论框架：**

1. **五大数字化新模式体系：**
   - 决策调控数字化新模式（提升数字化决策支持能力 + 提升行业调控能力）
   - 两烟生产数字化新模式（优质原料保障 + 智能制造）
   - 卷烟流通数字化新模式（市场营销数字化 + 现代化物流服务）
   - 专卖监管数字化新模式（现代化监管格局 + 数字技术支撑新型监管）
   - 综合管理数字化新模式（投资管理 + 财务管理 + 综合管理优化）

2. **数字化转型三大新变化：**
   - **变化一：** "三易"仍为主要因素，场景开发"各司其职"，不断追求更进一步。行业依赖 Excel 进行数据录入和统计（便于操作但易出现数据孤岛），SaaS 可快速开发应用（降低成本提升业务协作），核心系统如 ERP 和 MES 仍需高代码开发确保稳定性，DeepSeek 等大模型能力加强后可解决更多问题。
   - **变化二：** 全员提升与核心培养相结合，如何发挥业务条线数字人才的效率成为当下重点。提出"数字人才中台"概念，整合数据分析、产品等角色，集中"接单"、统一"交付"。
   - **变化三：** 业务流程重塑才能带来真正的数字化价值，需要管理保障和技术支撑，三者"你中有我、我中有你"。

3. **数字化场景开发原则：** "场景层级化、技术融合化、价值可量化"——工作上的难题才是数字化的课题。

4. **互联网发展三阶段理论：**
   - 互联网1.0 —— PC互联网时代：基于信息的数据化（文字、图像、音频、视频），依靠人工力量
   - 互联网2.0 —— 移动互联网时代：基于人的信息的数据化（心情、位置、形象、感受、动机、喜好），依靠自发发布
   - 互联网3.0 —— 物联网时代：基于物的信息的数据化（光线/压力/触摸/方向/位置/温湿度/红外/RFID/NFC感应等），智能采集

### 1.6 关于权重调整的理论依据

1. **场景层级化原则：** 数字化场景开发在结果导向的基础上要重视"场景层级化、技术融合化、价值可量化"，不同层级场景的指标权重应有所区别
2. **指标分层权重：** 异动分析中指标分为五层（核心量额→结构→客户→终端→数据质量），各层指标在归因分析中的权重应按重要性递减
3. **区间定向调控：** 针对不同档位卷烟设定区间阈值，推动市场调控过程由经验主观调控转变为数字指标客观调控
4. **货源属性评价：** 引入市场状态指标开展货源属性评价，指标权重需固化进平台系统中

### 1.7 关于数字化能力、时序特征的理论描述

**数字化能力理论：**
1. **数字化转型的本质：** 数字化场景开发要重视"场景层级化、技术融合化、价值可量化"，工作上的难题才是数字化的课题
2. **数据要素作用：** 强调"发挥数据要素作用"，整合行业数据和信息资源，提升经济运行和发展态势感知能力
3. **数据治理要求：** "数据清、规则明、逻辑通"——确保规则设定结合年度、季度产销规划数据
4. **数据准确性核心理念：** 先确认"数据是对的"再解释业务，数据流追踪覆盖采集→加工→看板→修正全链路
5. **数字化能力建设路径：** 从"分析三散"（月级别散、口径上散、报告归档散）到"六模块N场景"智能分析平台

**时序特征理论：**
1. **归因分析的时序维度：** 归因分析需关注首因、末因、线性、位置、时间等维度
2. **异动分析的时序特征：** 异动信号包含"自己的规律"和"整体的规律"，需区分个体异动与群体异动
3. **监测周期时序体系：** 日监测、周分析、月评估的时序监测模型，"周进月、月促季、季保年"的销售进度分析评价
4. **需求预测时序模型：** 年度、半年、月度需求预测分析与协议动态调整机制，增加访销周期预测以周为最小单位
5. **事前事中事后时序贯穿：** 投放预警机制需覆盖事前、事中、事后全过程
6. **同比/环比/连续性时序阈值：** 异动判定使用同比、环比、绝对量、贡献度、连续性等时序阈值

## 二、0801.docx —— 卷烟营销数据分析方法体系（帕累托/波士顿矩阵/RFM/漏斗）

### 2.1 文档主题和核心理论框架

**文档主题：** 卷烟营销领域四种核心数据分析方法的系统培训与实战应用，以及"六模块N场景"智能分析平台的构建。

**核心理论框架：**

文档提出**四种数据分析方法体系**，能使用同一份数据完成四种分析：

1. **帕累托分析** —— 20/80分层找关键
2. **波士顿矩阵** —— 份额×增长定资源
3. **RFM分析** —— 近频额客户分层
4. **漏斗分析** —— 阶段转化找短板

**能力要求（五种能力）：**
- 会判断客户贡献结构（帕累托做出ABC分层，说出每层管理动作）
- 会判断品牌组合位置（波士顿矩阵四象限，给出资源配置建议）
- 会做客户价值分层（RFM算出得分，识别重点维护/挽留/流失客户）
- 会定位漏斗流失环节（比较不同渠道的阶段转化率，找到最弱链路）
- 会把数据结论转成业务动作（不只读数字，每个结论对应"谁/做什么/何时/怎么复盘"）

### 2.2 涉及的评价维度和方法

#### 2.2.1 帕累托分析

**核心思想：** 少数对象贡献多数结果，是资源配置的优先级工具。本质不是数字——不是"20%一定贡献80%"，而是按贡献排序找到"关键少数"。

**输出有三件：** Top清单、累计占比曲线、ABC分层

**ABC分层标准：**
- A类：累计占比 < 80%（重点拜访、活动优先、库存优先保障）
- B类：累计占比 80%~95%（定向培育、提升潜力客户）
- C类：累计占比 > 95%（标准化触达、低成本维护）

**4个常见误区及修正：**
1. 误区：一定是"20%客户贡献80%" → 修正：不同行业不同，30/70、40/60都正常，看实际数据曲线
2. 误区：只看销量，不看毛利和风险 → 修正：A类大户可能有"销量大但利润低"或"集中风险高"
3. 误区：把C类客户当成可有可无 → 修正：长尾是基础流水，全部砍掉容易让大户议价能力变强
4. 误区：分层后没有动作 → 修正：每个分层后面必须跟"动作、责任人、复盘节点"

**应用案例：**
- 零售户违规类型贡献分析（违规类型、案件数、处罚金额、区县）
- 配送异常原因贡献分析（异常原因、线路、延误次数、损失时长）
- 费用项目/督办问题贡献分析（费用科目、金额、部门、问题件数）
- 监管对象分类管理（客户风险等级、案件增长率、历史案件占比）

#### 2.2.2 波士顿矩阵

**核心框架：**
- 横轴：市场份额（或相对份额）——代表"现在"的规模地位
- 纵轴：增长率——代表"未来"的成长性
- 四象限：明星（高份额高增长）、金牛（高份额低增长）、问题（低份额高增长）、瘦狗（低份额低增长）

**阈值定法（四种方法）：**

| 方法 | 横轴 | 纵轴 | 优点 | 缺点 |
|-----|------|------|-----|------|
| 均值法 | 份额均值 | 增长率均值 | 简单、自动平衡 | 容易把平均值附近的品牌分到不同象限 |
| 中位数法 | 中位数 | 中位数 | 抗极值、各象限品牌数相对平衡 | 中位数不一定代表业务意义上的高低 |
| 管理目标线法 | 市场目标（如20%） | 业务期望（如5%） | 可解释、和KPI挂钩 | 需先有清晰目标，不同年度可比性差 |
| 相对份额法 | 本品牌/最大竞品 | 增长率 | 更适合跨品牌比较 | 需要有"竞品销量"数据 |

**应用范围：** 不仅用于品牌，客户群、渠道组合、区域组合同样适用——只要横纵轴有清晰口径。

#### 2.2.3 RFM分析

**三个维度：**
- **R（Recency）**：最近一次消费时间，间隔越短客户越活跃
- **F（Frequency）**：消费频率，频率越高客户越忠诚
- **M（Monetary）**：消费金额，金额越高客户价值越大

**5分位评分法：**

| 得分 | R（间隔） | F（单数） | M（订购量） |
|-----|----------|----------|-----------|
| 5分（最佳） | 最近0~7天 | 最多40+单 | 最高2000+条 |
| 4分 | 8~21天 | 25~40单 | 1000~2000条 |
| 3分 | 22~40天 | 15~25单 | 500~1000条 |
| 2分 | 41~80天 | 8~15单 | 200~500条 |
| 1分（最差） | >80天 | <8单 | <200条 |

**8个客户分层及运营动作：**

| 分层名称 | RFM特征 | 业务含义 | 运营动作 |
|---------|---------|---------|---------|
| 重要价值客户 | R高F高M高 | 近频额都高——重点客户 | 专人维护、活动优先 |
| 重要发展客户 | R高F低M高 | 近期有大额订单但频次不稳 | 提升订购频次、组合推荐 |
| 重要保持客户 | R低F高M高 | 频次额度还在但最近变沉默 | 持续关怀、防止流失 |
| 重要挽留客户 | R低F低M高 | 历史值钱但近期沉默 | 重点回访、原因排查 |
| 一般价值客户 | R高F高M低 | 近期活跃但贡献不大 | 标准化维护 |
| 一般发展客户 | R高F低M低 | 近期接触但价值未起来 | 低成本培育 |
| 一般保持客户 | R低F高M低 | 频次还行但小客户 | 批量维护 |
| 流失风险客户 | R低F低M低 | 全维度低——流失边缘 | 低成本触达或战略放弃 |

**RFM应用案例：**
- 零售户守法经营活跃度分层（R为最近检查/巡查间隔，F为守法活动频次，M为合规贡献/风险）
- 客户配送服务分层（R为最近服务异常间隔，F为配送频次，M为配送量/投诉影响）
- 内部服务对象分层（R为最近需求时间，F为需求次数，M为事项影响）

**RFM + LTV组合客户分类：**
- 高RFM + 高LTV → "钻石客户"，重点维护，提供专属权益
- 高RFM + 低LTV → "机会客户"，用增购/交叉销售提升价值
- 低RFM + 高LTV → "沉睡潜力客户"，推送唤醒活动
- 低RFM + 低LTV → "边缘客户"，减少资源投入

#### 2.2.4 漏斗分析

**核心指标：**
- 阶段转化率 = 下阶段人数 / 上阶段人数
- 阶段流失量 = 两阶段人数差

**本质：** 帮助把"营销效率不行"这种宽泛说法变成"X渠道在Y阶段流失了Z人"的精确诊断。

**4个常见误区及修正：**
1. 误区：只看最终转化率，忽略中间掉点 → 修正：要看每一步
2. 误区：只看百分比，忽略流失绝对量 → 修正：转化率低但基数小不重要；转化率不算低但基数大才是大坑
3. 误区：所有渠道混在一起看 → 修正：必须按渠道分开
4. 误区：阶段定义不清楚/不同渠道阶段不可比 → 修正：动手前先把每个阶段的"判定标准"写清楚

**漏斗分析应用案例：**
- 案件线索办理漏斗（线索数→核标数→立案数→结案数→整改数）
- 督办事项闭环漏斗（事项收集→立项→办理→反馈→销号）

## 三、0801-2.docx —— 趋势分析与回归、AHP层次分析法

### 3.1 文档主题和核心理论框架

**文档主题：** 趋势分析与回归分析方法，以及AHP层次分析法在信息采集样本点模型构建中的应用。

**核心理论框架：**

#### 3.1.1 回归分析理论

**回归的起源与定义：**
- 回归（Regression）由英国生物学家弗朗西斯·高尔顿（Francis Galton）提出
- 回归是研究一个变量和另外一个变量的变化关系，其中一个变量叫因变量，另外一个叫自变量
- 多元回归是研究一个因变量和多个自变量之间的关系

**回归分类：**
- 线性回归
- 逻辑回归
- 多项式回归
- 逐步回归
- 岭回归
- 套索回归

**一元线性回归：**
- 最简单的线性回归，有两个变量：因变量（Y）和自变量（X）
- 拟合公式：**Y = a + bX**
- 核心规律：整体趋势会向平均值发展（回归到均值）

#### 3.1.2 归因分析要素

文档明确列出了归因分析的四个维度：
- **首因** —— 第一个原因/触发因素
- **末因** —— 最后一个原因/直接原因
- **线性** —— 线性关系/趋势
- **时间** —— 时间序列特征

#### 3.1.3 AHP层次分析法

**AHP定义：** AHP = Analytic Hierarchy Process，中文叫层次分析法。

**核心方法：** 把复杂问题拆成"目标—准则—方案"三层结构，再用权重计算，得出最优选择。

**三层结构：**
- **目标层：** 我要找最好的采集点（最终目标）
- **准则层：** 判断一个采集点好不好的标准（评价维度）
- **方案层：** 候选的几个具体委售户（备选方案）

### 3.2 涉及的评价维度和方法

**AHP层次分析法实例（国庆旅游目的地选择）：**

| 准则 | 说明 |
|-----|------|
| A1: 旅游成本 | 总花费 |
| A2: 景点吸引力 | 好玩程度 |
| A3: 交通便利性 | 路程和便捷度 |

**判断矩阵构造与权重计算（几何平均法）：**
- 景点吸引力比旅游成本重要3倍 → A1权重 = ∛(1×1/3×1/2) = ∛(1/6) ≈ 0.550
- 交通便利性比旅游成本重要2倍 → A2权重 = ∛(3×1×2) = ∛6 ≈ 1.817
- 景点吸引力比交通便利性重要2倍 → A3权重 = ∛(2×1/2×1) = ∛1 = 1.000

**综合得分计算：**
- 三亚综合得分 = 0.369（推荐选择）
- 西安综合得分 = 0.337（次优选择）
- 成都综合得分 = 0.295（第三选择）

### 3.3 具体的指标体系建议

**常用分析方法体系：**

| 方法/工具 | 核心思路 | 典型用途 |
|---------|---------|---------|
| A/B测试 | 随机将用户/店铺/地区分成"实验组vs对照组"，只在实验组推苗促销/活动/页面设计，然后比较两组效果差异 | 衡量新活动、优惠券样式/门槛/满赠门槛/激励政策是否比当前或无活动更好 |
| 时间序列对比/同期对比/环比 | 比较活动期间vs活动前vs去年同期；也观察月/周/日趋 势态势 | 判断整体业务趋势；估计活动启动前后的自然波动；季节性因素剔除 |
| 分群/细分分析 | 把用户/商品/门店分组看不同群体的响应情况；常用RFM；按渠道/地理/规模分群 | 掌握谁对活动最敏感；资源优先投给高响应群体；优化定向度 |
| 倾向得分匹配(PSM) | 当不能完全随机时，用统计方法匹配实验组与对照组在基线上的特征，使两组可比性提高 | 用在优惠券发放/满赠/不完全覆盖人群的活动中估增量 |

### 3.4 算法/模型相关理论

**回归分析模型：**
- 一元线性回归：Y = a + bX
- 多元回归：一个因变量与多个自变量的关系
- 回归类型：线性、逻辑、多项式、逐步、岭、套索回归

**AHP层次分析法模型：**
1. 构建层次结构（目标层—准则层—方案层）
2. 构造判断矩阵（两两比较准则的重要性）
3. 权重计算（几何平均法）
4. 计算各方案的综合得分
5. 排序选择最优方案

**倾向得分匹配(PSM)模型：**
- 用于非完全随机实验的场景
- 通过统计方法匹配实验组与对照组在基线上的特征
- 提高两组可比性，用于估增量

### 3.5 对卷烟零售户经营能力评价的具体要求

1. **信息采集样本点评价：** 使用AHP层次分析法构建信息采集样本点模型，目标层为"找最好的采集点"，准则层为判断采集点好不好的标准，方案层为候选的具体委售户
2. **多准则权重评价：** 通过AHP方法将复杂评价问题拆解为目标-准则-方案三层结构，用权重计算得出最优选择
3. **趋势评价能力：** 通过回归分析判断零售户经营指标的趋势变化，整体趋势向平均值发展

### 3.6 关于权重调整的理论依据

1. **AHP权重计算方法：** 使用几何平均法计算权重，通过两两比较构造判断矩阵，确保权重的科学性和一致性
2. **判断矩阵的标度：** 采用1-9标度法进行两两比较（如"重要3倍"、"重要2倍"等）
3. **权重可调整性：** 准则层的权重可根据实际业务需求调整判断矩阵，从而改变各准则的权重分配
4. **综合得分权重加权：** 各方案的综合得分 = 各准则权重 × 方案在各准则下的得分之和

### 3.7 关于数字化能力、时序特征的理论描述

**数字化能力理论：**
1. **信息采集数字化：** 通过AHP层次分析法实现信息采集样本点的科学选择，将主观判断转化为可量化的权重计算
2. **A/B测试数字化能力：** 随机分组实验，量化评估活动效果
3. **倾向得分匹配(PSM)数字化能力：** 在非随机场景下通过统计方法实现可比性评估

**时序特征理论：**
1. **回归分析的时间趋势：** 回归分析本质上研究变量随时间的变化关系，Y = a + bX中的X可以是时间变量
2. **"整体趋势向平均值发展"：** 高尔顿回归理论的核心——极端值会向均值回归，这是时序预测的重要理论基础
3. **归因分析的时间维度：** 归因分析需关注"首因、末因、线性、时间"四个维度，其中"时间"维度专门强调时序特征
4. **时间序列对比方法：** 活动期间vs活动前vs去年同期的对比，月/周/日趋势观察，季节性因素剔除
5. **时间序列对比的三个层次：** 同期对比（同比）、环比对比（环比）、趋势对比（月/周/日趋势）
