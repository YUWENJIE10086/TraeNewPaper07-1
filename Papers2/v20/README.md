- 保留 `v18-3-3-2/xg4` 的核心研究问题和“排序 + 人工复核”方向，不为追求模型复杂度推倒重来。

- 自 v20 起，ChatGPT 每次生成的论文正文、HTML/Markdown、图表源码、CSV、实验表格和中间审稿材料均同步提交到本目录或其子目录；此前 v20 系列产物逐步补齐。

## 当前已经确认的A级统计/复现问题

1. `xg-3/code/08b_suppl_rerun.py` 的500次置换检验把置换效应与“置换效应自身均值”比较，现有 `P=0.974` 不是针对真实观测效应的经验P值，必须重算。
2. 正文声称 PSM 使用“0.02卡钳”，现有代码实际执行的是无放回贪心最近邻，没有卡钳筛除。
3. 名义6指标结果评分中，当前权重文件只有顺价指数、毛利率、存销比3项权重大于0，其余3项权重为0，正文不能继续把它当成实质性的“六维综合状态”。
4. 多个变量缺失率较高，其中 `new_cust` 约59.6%，`full_surf` 约46.9%，`util` 约45.6%，毛利率和存销比约39.1%，需要缺失敏感性分析。
5. PSM平均绝对SMD降至约0.057，但 `fill_pre` 和 `demand_gap_pre` 匹配后绝对SMD仍约0.214，不能只用平均值宣称平衡充分。
6. 处理前负对照显著（P<0.001），因此论文必须维持“关联排序/人工复核”的证据等级，不能升级为无偏自动因果决策。
7. 高排序组与其余处理样本的“改善率”均为59.3%，补充Mann–Whitney检验P≈0.125；当前均值差主要受分布右尾影响，需要更谨慎解释。
8. 部分补充结果由硬编码脚本写回，图表脚本又存在跨版本Windows绝对路径；v20将改成单一事实源、相对路径和自动校验。

## v20-6 当前术语与标题原则

- 标题不再使用“诚实因果森林”。“诚实”仅指 honest splitting，是估计实现机制，不是行业研究创新点。
- 当前首选题名：`卷烟品规供给收缩差异化复核方法研究`。
- 若希望在题名中保留算法，可用：`基于因果森林的卷烟品规供给收缩差异化复核研究`。
- 方法部分首次写“采用诚实样本分割机制（honest splitting）的因果森林”，后文统一简称“因果森林”。
- 不将 honest splitting 表述为“保证因果可靠”；它不能解决未测混杂、共同支持不足与非随机处理问题。
