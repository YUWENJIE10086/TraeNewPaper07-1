## v20-8 最终方法口径

1. 原始面板：3149条品规×月份记录，2025-01至2026-06。
2. 结果评分 `S*` 与处理定义独立，仅使用：顺价指数、毛利率、存销比（反向）和动销率；每个 `ym` 内转成百分位后等权合成。
3. 代理事件 `T` 仅在当月与上月 `fill` 均可观测时定义：当月满足率≤该 `ym` 横截面P35，且较上月下降>2个百分点。
4. 结果：`Y=S*(t+1)-S*(t)`；真正处理前负对照：`Y_pre=S*(t-1)-S*(t-2)`。
5. 所有动态经营画像统一滞后至 `t-1`；静态品规类别与价位段保留。
6. 方法准确命名为 **R-learner异质性效应排序（LightGBM基学习器）**。旧 v18 脚本虽曾称“causal forest”，实现本质为R-learner式残差化伪结果回归，因此 v20-8 不再误称因果森林。
7. 验证链：滚动严格时间外DR验证 + Top-k业务基线比较 + 12随机种子稳定性 + OOF共同支持域AIPW + 真正处理前负对照。

## v20-8 最终关键结果

- 最终分析样本：1825条、177个品规、253个代理事件。
- 共同支持域内AIPW：2.577，95%CI 0.456～4.699；域外处理样本占0.40%。
- 真正处理前负对照：-0.889，95%CI -3.792～2.014，区间跨0。
- 严格时间外测试：2025-09至2026-06共10个月、1059条测试观测；Top-30%月均DR增益2.528，7/10个月为正，但月份聚类bootstrap 95%CI为-5.989～5.928。
- Top-30%相对测试集总体DR增益+0.470；相对存销比排序+2.657；相对综合状态评分-2.494。
- 12随机种子：除基准seed外，tau排序Spearman中位数0.592；Top-20%名单重合率中位数53.2%。
- 结论：模型能补充单一库存指标，但尚未稳定超过综合状态评分，且精确名次对随机种子仍敏感。当前最合适的定位是“状态评分后的第二层人工复核信号”，不自动确定收缩对象和减量幅度。

## 最终代表性案例选择规则

`experiments/0916_0831/representative_cases_final.csv` 保留严格时间外且 `T=1` 的观测，仅按 `tau_oot` 排序选最高5例与最低5例，不按下一期结果好坏挑选。高排序中保留下一期接近0或略负的反例，低排序中也保留下一期改善的反例，用于证明模型属于概率性排序工具而不是确定性决策器。

正式投稿前应根据单位保密要求决定是否将真实品规名匿名化；满足率降至0的代理事件需优先核查真实断货、策略性停供或数据异常，不能直接解释为主动收缩。
