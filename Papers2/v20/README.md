## 目标

- 保留 v18-3-3-2/xg4 的核心研究框架，不做无依据的推倒重来。
- 按《中国烟草学报》审稿逻辑重构“研究问题—方法—证据—业务应用—边界”。

- 重新撰写题名、摘要、关键词、引言、方法、结果、讨论和结论。
- 对可复现实验重新运行代码；未经重新计算的数据不冒充新实验结果。
