## Step 1: 数据准备与特征工程（第1周）

### 1.1 数据读取与合并

**目标**：将15个Excel文件合并为一个832行×26列的特征矩阵。

**操作步骤**：

```
1. 读取客户档案列表（排程模式）.xlsx → 获取832户客户主表
2. 循环读取12个月销售情况文件 → 按客户编码聚合为月均指标
3. 循环读取12个月扫码统计文件 → 按客户编码聚合为扫码指标
4. 循环读取12个月店铺运营文件 → 按客户编码聚合为盈利指标
5. 循环读取12个月门店排行文件 → 按客户编码聚合为补充指标
6. 读取信用等级分布统计 → 关联信用等级
7. 读取客户分档销售统计 → 提取品规宽度
8. 读取客户方差明细列表 → 提取销售波动率
9. 读取数采户查询 → 提取合规性指标
10. 以客户编码为主键，左连接所有特征
```

**关键代码逻辑**：
```python
# 伪代码
import pandas as pd

# 1. 读取主表
main_df = pd.read_excel('客户档案列表（排程模式）.xlsx')

# 2. 聚合12个月销售数据
sales_list = []
for month in range(1, 13):
    df = pd.read_excel(f'销售情况/销售情况25{month:02d}.xls')
    sales_list.append(df)
sales_df = pd.concat(sales_list).groupby('客户编码').mean()

# 3. 合并所有特征
feature_df = main_df.merge(sales_df, on='客户编码', how='left')
# ... 依次合并其他数据源
```

**注意事项**：
- 客户编码含尾随空格，合并前需 `.str.strip()`
- 店铺运营情况文件有多级表头，需 `header=[0,1]` 读取
- 部分数值列存储为文本类型，需 `pd.to_numeric()` 转换

### 1.2 特征计算

**目标**：基于原始字段计算26维特征。

**计算清单**：

| 序号 | 特征名称 | 计算公式 | 数据源 |
|------|---------|---------|--------|
| 1-5 | 经营环境5维 | 分类变量编码 | 客户档案列表 |
| 6-8 | 订购量/额/价 | 12个月均值 | 销售情况×12 |
| 9-10 | 品规宽度/均衡度 | 直接读取/公式(3) | 客户分档销售统计 |
| 11-14 | 扫码4维 | 12个月均值/求和 | 地市扫码统计×12 |
| 15-21 | 盈利7维 | 12个月均值 | 店铺运营×12 + 门店排行×12 |
| 22-26 | 数字化5维 | 直接读取/编码 | 扫码统计 + 客户档案 + 信用等级 |

### 1.3 数据预处理

**操作步骤**：

```
1. 缺失值处理：
   - 数值型：用该列中位数填充
   - 分类型：用该列众数填充
   - 缺失率>50%的列：删除

2. 异常值检测：
   - 对每个数值列，用3σ准则检测异常值
   - 将超过μ+3σ或低于μ-3σ的值截断为边界值

3. 分类变量编码：
   - 有序分类（如信用等级AAA-D）：Label Encoding（1-7）
   - 无序分类（如业态类型）：One-Hot Encoding

4. 数值标准化：
   - 正向指标：公式(1) Min-Max归一化
   - 负向指标：公式(2) 反向归一化
```

- `feature_matrix.csv`：832行×26列特征矩阵
