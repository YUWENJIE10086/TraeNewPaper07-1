## 二、摘要写作规律

### 2.1 四段式结构

所有论文摘要均遵循【目的/背景】→【方法】→【结果】→【结论】四段式：

| 论文 | 起笔方式 | 方法描述句式 | 结果呈现方式 | 结论措辞 |
|------|---------|-------------|-------------|---------|
| P1 | "丰富……维度，建立……标准" | "提出……解决方案，介绍……" | "相比LR，准确率分别提升9.09%和15.43%" | "实践证明……可以很大程度提升……" |
| P2 | "针对……存在的问题" | "首先……采用……最终……" | "分别是B类的3.24、29.87、6.41、8.22倍" | "可为……提供支持" |
| P3 | "针对……导致……的现状" | "在数据治理阶段，首先……在状态评估阶段，基于……" | 定性："与实际市场行情高度契合" | "可为……提供科学依据" |
| P4 | "数据驱动……是……的关键" | "基于……构建……模型，首次引入……" | 定性："能显著提升……水平" | "可为……提供理论支撑和实践指导" |
| P5 | "监测市场状态是……的重要手段" | "首先利用……然后采用……" | "不仅能够……同时也实现了……" | — |
| P6 | "本文在……基础上，借鉴……" | "该方法通过……来判断……" | — | "为……提供一种可借鉴的方法论" |

### 2.2 摘要字数

- 最短：P6约150字
- 最长：P1/P5约350字
- 多数：200-300字

## 三、引言写作规律

### 3.1 三种起笔方式

**方式A：行业现状描述型**（P1/P3/P4）
- P1："烟草行业内常规投放策略包括按'档位'、按'档位+价位'……"
- P3："卷烟营销网络是烟草商业企业最重要的经营基础之一……"
- P4："随着消费者需求多元化和市场竞争加剧……"

**方式B：痛点直击型**（P2/P5/P6）
- P2："传统的新品培育模式通常包含以下2种方案……存在较强的主观意识"
- P5："准确监测与评价市场状态是……的基础"
- P6："如何实现精准营销……是各卷烟企业普遍面临的重大课题"

### 3.2 文献综述结构

统一采用"已有研究做了什么 → 存在什么不足 → 本文如何改进"三段逻辑：

```
句式模板：
"XX等[N]提出/构建了……，[方法/结果]，但[不足]"
"XX等[N]基于……，[方法/结果]，然而[局限]"
"综上所述，现有研究存在N方面不足：①……②……③……"
```

### 3.3 创新点表述位置与措辞

- **位置**：100%在引言末尾（文献综述之后、方法之前）
- **措辞**：P4最直白（"①②③"编号+三个"首次"），其他用"本文提出了……改进了……"

## 四、公式设计规律

### 4.1 公式递进链

所有论文的公式遵循五阶段递进：

```
数据预处理 → 特征/指标计算 → 权重/模型 → 评价/阈值 → 应用/决策
```

### 4.2 公式描述四步法

```
步骤1（公式前）：设变量、给假设条件
"假设在某投放周期T内，n个零售户的某观测值……"
"针对第j个维度，对第m个零售终端的第n个标签进行……"

步骤2（公式）：给出编号公式
"d_{mn,j} = (f_{mn,j} - min(f)) / (max(f) - min(f))    (3)"

步骤3（公式后）：逐个解释变量
"其中，d_{mn,j}表示……，f_{mn,j}表示……，max(f)表示……"

步骤4（业务含义）：说明公式的物理/业务意义
"该指标越接近1，表示品规分布越均衡"
```

### 4.3 公式数量

- 最少：P3的4个
- 最多：P5的18个
- 中位数：9-12个
- 建议：本文设计14个公式，处于中等水平

## 六、结论写作规律

### 6.1 两种格式

**格式A：编号列举式**（P1，定量论文）
```
"(1) 基于本文提出的……，准确率可以达到90%以上……
(2) 模型预测精度对比为：DXGBOOST > XGBOOST > LR……
(3) DXGBOOST模型对比XGBOOST，ACC从85.14%提升到88.27%……"
```

**格式B：段落总结式**（P3/P4，定性论文）
```
"针对……问题，本研究提出……框架：先通过……再基于……
实证结果表明，该方法能够更稳定、可解释地……
可为……提供量化依据。"
```

### 6.2 展望写法

```
"未来将……"
"下一步将引入……"
"未来研究方向包括：(1)…… (2)…… (3)……"
```

## 七、整体行文逻辑规律

### 7.1 章节过渡方式

- **引言→方法**："本文从一个新的角度……"或直接进入方法章节
- **方法→实验**：用一段话交代数据来源和实验设计
- **实验→应用**：用一段话总结实验发现，引出应用价值

### 7.2 主题句写法规律

| 段落类型 | 主题句模板 | 示例 |
|---------|-----------|------|
| 定义型 | "……是……的关键/基础/前提" | "构建科学、有效的指标体系是……的关键前提" |
| 方法型 | "为……，采用/提出……" | "为从高维特征中挖掘有效变量，采用相关性分析……" |
| 问题型 | "目前/现有研究……相对较少/存在不足" | "目前国内外针对……的研究相对较少" |
| 结果型 | "从表X可以看出/可见……" | "从表4可以看出，非线性模型……" |

## 八、对本文写作的指导建议

### 8.1 应该学习的写法

1. **摘要**：采用P1的四段式标签写法，结果部分给出具体数据
2. **引言**：采用P3的"框架先行"过渡方式，在引言末尾给出整体框架描述
3. **公式**：采用P2的编号公式+四步描述法
4. **创新点**：采用P4的编号列举式，用"首次"强调原创性
5. **结果**：采用P1的"从表X可以看出"句式
6. **结论**：采用P1的编号列举式，每条含具体数据

### 8.2 应该避免的写法

1. 避免像P6那样摘要过短（仅150字）
2. 避免像P3那样结果部分无具体数值
3. 避免像P1那样公式不编号
4. 避免文献综述只说优点不说不足

### 8.3 本文的最佳写作模板

综合六篇论文的优点，本文应采用：

```
摘要：P1四段式 + P2量化结果
引言：P3框架先行 + P4编号创新点
方法：P2编号公式 + P4变量表
实验：P5多组对比 + P1量化表述
结论：P1编号列举 + P4展望式
```
