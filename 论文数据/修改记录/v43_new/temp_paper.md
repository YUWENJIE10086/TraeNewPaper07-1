**摘要：**针对烟草零售终端扫码数据丰富但缺乏前瞻性预测预警能力的问题，提出基于梯度提升决策树的时序预测框架，预测未来终端运行指标并量化零售终端运行风险，实现提前预警。以兴山县133家零售终端扫码数据为样本，将运维办法7项指标映射为14个预测目标，分别按3/5/7/15/30天五种时间窗口进行预测，以各窗口的上期和同期数据为特征训练模型，以梯度提升决策树（LightGBM）为主模型，对比随机森林、线性回归和简单基线四种方法。实验证明，梯度提升决策树表现最优，整体决定系数达0.933。然后构建零售终端运行风险评分四级预警机制，可预警终端账实不符、扫码异常等风险。本研究为烟草零售终端的运行监测、客户经理重点走访排序和客服部货源投放调整提供了数据驱动的决策支持。

**0引言**

湖北烟草\"知音通\"零售终端管理系统推广以来，兴山县零售终端积累了扫码记录、在线时长等多维度运行数据^\[1\]^。现行运维管理办法建立了覆盖7项指标的周评价机制，满分100分。然而该机制基于已发生数据事后计算得分，无法回答下个周期指标如何变化。客户经理需走访较多终端，但缺乏量化排序依据，难以制定重点走访计划。

姜思明等^\[1\]^提出\"数据治理---状态评估\"一体化框架，采用K-means聚类剔除异常终端。李天举等^\[2\]^基于Stacking集成学习进行烟草异常数据挖掘，查实率提升至94.3%。刘忠华等^\[3\]^基于LightGBM模型验证了梯度提升决策树在分类预测中的有效性。然而现有研究多聚焦事后评估，对多指标同步预测和前瞻性预警关注较少。

本文以兴山县133家零售终端2026年1至5月扫码数据为基础，提出基于梯度提升决策树（LightGBM）的时序预测预警框架：（1）采用上月趋势加历史同期的双维时序特征编码方案，将运维办法7项指标映射为14个预测目标；（2）以LightGBM为核心模型，对比线性回归、随机森林和简单基线共四种模型，采用决定系数R²衡量回归精度，以精确率-召回率曲线、受试者工作特征曲线和四象限分析验证分类效果；（3）构建以基期行为为主、预测偏差为辅的零售终端运行风险评分，制定四级预警等级分类；（4）输出各终端预警等级及预警原因提示，为客户经理重点走访排序、客服部货源投放调整和市局异常排查提供决策依据。

**1.2.2 模型对比设计**

本文选取四种代表性模型进行横向对比，覆盖从简单线性到复杂非线性的算法谱系。

（1）线性回归（Linear
Regression，LR）。线性回归是一种基于最小二乘法的参数化模型，假设预测目标与特征之间存在线性可加关系，通过最小化残差平方和估计模型参数。模型形式为：

$ŷ\  = \ w^{T}x\  + \ b$*(1)*

其中，ŷ为预测值，w为权重向量，x为特征向量，b为偏置项。

（2）随机森林（Random
Forest，RF）^\[3\]^。随机森林是一种基于Bagging策略的集成学习方法，通过对训练集进行有放回抽样构建B棵决策树，每棵树在节点分裂时随机选取部分特征，最终对各树预测取均值输出结果。模型形式为：

$ŷ\  = \ \frac{\sum_{b = 1}^{B}{h_{b}(x)}}{B}$*(2)*

其中， B为决策树数量，$h_{b}(x)$为第b棵树的预测值。

（3）LightGBM（Light Gradient Boosting
Machine）^\[3\]^。LightGBM是一种基于GOSS和EFB的高效梯度提升决策树，在第

$F_{t}(x)\  = \ F_{t - 1}(x)\  + \ f_{t}(x)$*(3)*

$F_{t - 1}(x)$轮迭代中，模型在前轮的基础上追加一棵树，使得当前损失最小化。GOSS保留大梯度样本并随机采样小梯度样本减少计算量，EFB合并互斥特征降低维度。已有研究^\[1-2\]^验证了其在烟草领域中的优异性能。

（4）简单基线（Naive
Baseline，NB）。直接使用上期实际值作为目标期预测值，即对第j项指标：

$ŷ_{j,T + 1}\  = \ y_{j,T}$*(4)*

式中：$ŷ_{j,T + 1}为$第j项指标第T+1期的预测值，$y_{j,T}$
为第j项指标第T期的实际值。该基线衡量机器学习模型相比朴素预测的增量价值。

**1.2.3 评价指标**

评估体系分回归和分类两个层面。回归层面采用决定系数R²衡量预测值与实际值的拟合精度，R²越接近1说明预测越准确。分类层面将每个预测目标的预测值按阈值转换为二分类标签，14个目标的分类结果取R²加权平均值。具体指标如下：

（1）决定系数R²。R²衡量回归模型对因变量方差的解释比例，取值范围负无穷至1，越接近1说明模型拟合越好。计算公式为：

$R^{2}\  = \ 1\  - \ \frac{\sum_{i = 1}^{n}{y_{i}\  - \ ŷ_{i}}^{2}}{\sum_{i = 1}^{n}{y_{i}\  - \ ȳ}^{2}}$*(5)*

$$y_{i}为第i个实际值，ŷ_{i}为第i个预测值，ȳ为实际值的均值，n为样本数。$$

（2）精确率P。精确率衡量模型预测为正例的样本中真正为正例的比例，反映模型预测正例的可靠程度。计算公式为：

$P\  = \ \frac{TP}{TP\  + \ FP}$*(6)*

TP为真正例数，FP为假正例数。

（3）召回率R。召回率衡量所有真实正例中被模型正确识别的比例，反映模型发现正例的能力。计算公式为：

$R\  = \ \frac{TP}{TP\  + \ FN}$*(7)*

FN为假反例数。

（4）F1值。F1值是精确率和召回率的调和平均值，综合衡量模型的精确性和完整性。计算公式为：

$F_{1}\  = \ 2\  \times \ \frac{P\  \times \ R}{P\  + \ R}$*(8)*

（5）精确率-召回率曲线下面积（Precision-Recall Area Under
Curve，PR-AUC）。以召回率为横轴、精确率为纵轴绘制曲线，曲线下面积越大说明高风险终端识别效果越好，在正负样本不均衡时比受试者工作特征曲线下面积更能反映模型性能。

（6）受试者工作特征曲线下面积（Receiver Operating Characteristic Area
Under
Curve，ROC-AUC）。受试者工作特征曲线以假阳性率为横轴、真阳性率为纵轴绘制，曲线下面积越接近1说明模型区分能力越强。真阳性率即召回率，假阳性率为负例中被错误判为正例的比例。

（7）四象限一致性。以预测值和实际值的中位数为界将终端分为四个象限，Q1为实际高且预测高、Q3为实际低且预测低，这两类为正确预测；Q2为低估终端、Q4为高估终端。四象限一致性为正确预测终端数占总样本数的比例，从业务视角衡量预测结果对管理决策的参考价值。

**3预警机制与应用**

**3.1 预警机制设计**

零售终端运行风险评分以基期行为得分为主要依据，权重70%，预测偏差得分为辅助调整，权重30%。基期行为得分反映终端当前经营状态的基础运行风险水平，预测偏差得分反映未来可能的变化趋势。计算公式为：

$S\  = \ 0.7\  \times \ S_{base}\  + \ 0.3\  \times \ S_{dev}$*(9)*

式中：S为零售终端运行风险综合评分，取值0至100分；

$$S_{base}为基期行为得分，基于上期各项指标的实际表现计算；S_{dev}为预测偏差得分，基于预测值与基期值的相对偏差计算。$$

基期加成规则：日均扫码小于5笔加12分，小于10笔加6分；聚合支付小于1笔加8分；在线天数使用率低于60%加10分。四级阈值：大于等于60分红色预警，40至59分橙色预警，20至39分黄色预警，小于20分正常。基期行为占70%权重，终端当前经营状态是运行风险判断的主要依据；预测偏差占30%，捕捉未来变化趋势。

**3.2 多层级决策应用**

基于零售终端运行风险评分结果，构建三级管理层决策体系：

（1）客户经理层面：根据评分排序制定重点走访计划，优先走访橙色和红色预警终端。预警可识别终端账实不符、扫码异常等风险，红色预警需立即实地走访，橙色预警需本周期走访。走访时携带预警诊断报告，实现精准问题定位。

（2）县局客服部层面：统计各片区预警占比，对预警比例偏高的片区优先调整货源投放策略。预测扫码量上升的终端可适当增加紧俏货源投放量；预测大幅下降的终端应暂缓投放并优先排查原因，将预测结果与品规市场状态相结合。

（3）市局营销中心层面：汇总各区县运行风险指数进行横向排名和纵向趋势分析，从全局角度优化投放策略。多窗口策略可灵活支持3天应急排查、7天周评价、15天订货调整和30天月度考核等不同场景。营销中心可提前掌握整体运行风险态势，统筹调配资源。

**4结论**

本文以兴山县133家零售终端2026年1至5月扫码数据为基础，对比了四种模型，采用决定系数R²衡量回归精度，以精确率-召回率曲线、受试者工作特征曲线和四象限分析进行分类评估，设计了以基期行为为主、预测偏差为辅的零售终端运行风险评分四级预警机制。主要结论如下：

（1）梯度提升决策树在零售终端多指标时序预测中表现最优，整体决定系数R²=0.933，较线性回归提升0.057，较随机森林提升0.011，证实序列化纠错机制在小样本时序预测中表现优秀。精确率-召回率曲线下面积达0.8302、受试者工作特征曲线下面积达0.8108、四象限一致性83.6%，模型在运行风险识别上可靠有效。这一发现为烟草行业从\"事后评估\"向\"事前预警\"转型提供了新思路。

（2）零售终端运行数据呈现\"近期趋势+季节周期\"双维规律性。上期特征反映经营趋势，同期特征捕捉季节性规律，二者结合的编码方案使模型在五种窗口下均能稳定预测14项指标。扫码量和有效时段数合计贡献超过60%，揭示终端活跃度是运行风险的核心驱动因素。

（3）本研究建立了\"指标体系---特征编码---模型预测---风险评分---预警应用\"的完整方法论框架，构建了以基期行为为主、预测偏差为辅的零售终端运行风险评分四级预警机制，可预警终端经营风险。多窗口策略灵活支持应急排查、月度考核等多种场景，为各级管理人员提供了可量化的提前规划工具。
